# gost-server.ext

`gost-server.ext` — настройки расширений X.509 для серверного сертификата Nginx. OpenSSL читает их при выпуске сертификата через `-extfile /work/gost-server.ext` и включает в `gost-server.crt`. Сам Nginx этот `.ext` не читает.

```ini
basicConstraints = critical,CA:FALSE
keyUsage = critical,digitalSignature,keyAgreement
extendedKeyUsage = serverAuth
subjectKeyIdentifier = hash
authorityKeyIdentifier = keyid,issuer
subjectAltName = @server_names

[server_names]
DNS.1 = localhost
IP.1 = 127.0.0.1
IP.2 = 10.0.2.2
```

## Что означает каждое поле

| Поле | Для чего нужно |
|---|---|
| `basicConstraints = critical,CA:FALSE` | Указывает, что это конечный серверный сертификат. Он не является сертификатом УЦ и не предназначен для выпуска других сертификатов. |
| `keyUsage = critical,digitalSignature,keyAgreement` | Разрешает использовать ключ для цифровой подписи (`digitalSignature`) и согласования общего секрета (`keyAgreement`). Конкретное использование зависит от выбранного профиля TLS. |
| `extendedKeyUsage = serverAuth` | Задаёт назначение сертификата — подтверждение подлинности TLS-сервера. |
| `subjectKeyIdentifier = hash` | Создаёт идентификатор открытого ключа сервера. Здесь `hash` означает SHA-1 от открытого ключа, а не алгоритм подписи сертификата. |
| `authorityKeyIdentifier = keyid,issuer` | Помогает найти сертификат подписавшего УЦ. `keyid` берёт идентификатор его ключа, `issuer` позволяет добавить имя и серийный номер сертификата УЦ, если идентификатор недоступен. |
| `subjectAltName = @server_names` | Добавляет SAN — имена и IP, для которых действителен сертификат. `@server_names` ссылается на секцию ниже. |

`critical` требует от клиента распознать и обработать расширение. Если клиент его не поддерживает, сертификат должен быть отклонён.

## Адреса в SAN

- `[server_names]` — секция со списком адресов.
- `DNS.1 = localhost` — для подключения по имени `localhost`.
- `IP.1 = 127.0.0.1` — для подключения по IPv4 loopback на компьютере.
- `IP.2 = 10.0.2.2` — для обращения из стандартного Android Emulator к loopback компьютера, на котором он запущен.

Числа `.1`, `.2` различают записи одного типа. Порт `8483` и путь `/api/` в SAN не указываются. Для другого имени или IP нужно добавить соответствующую запись и заново выпустить серверный сертификат.

## Что важно помнить

Изменение `.ext` не меняет уже выпущенный `.crt`. После перевыпуска сертификат нужно перечитать в Nginx.

Алгоритм ГОСТ, набор параметров ключа, алгоритм подписи и срок действия задаются отдельно при создании ключа и выпуске сертификата. Этот файл также не устанавливает доверие к корневому УЦ и не заменяет импорт CRL в МП БР.

Описание расширений — [документация OpenSSL](https://docs.openssl.org/3.0/man5/x509v3_config/).
